    LOCAL PYTHON WORKBENCH

    Get the full workbench

    Install the Gazoken source checkout to use the local three-phase framework and its currently available Python measurements. Planned methods are still under development.

    1. Install Python 3.11 or newer.
    2. Clone or download the Gazoken source repository.
    3. From the checkout, run:
    python3 -m venv .venv
.venv/bin/python -m pip install -e '.[test]'
.venv/bin/gazoken

    Then open http://127.0.0.1:8765/.
